# AURIX — Platinum Collection

An immersive 3D luxury jewellery experience built with **A-Frame** and **WebGL**, showcasing the AURIX Platinum Collection through minimal design, cinematic lighting, and interactive product focus.

---

## ✨ Overview

AURIX Platinum Collection is a concept luxury jewellery showcase featuring three platinum rings:
- **AURIX NOCTIS**
- **AURIX AETHER**
- **AURIX OBSIDIAN**

The experience focuses on:
- Minimal luxury UI
- Interactive 3D product exploration
- Smooth transitions and focus states
- Editorial, high-end brand presentation

---

## 🛠 Tech Stack

- **HTML5 / CSS3**
- **JavaScript (Vanilla)**
- **A-Frame (WebXR / WebGL)**
- **GLTF 3D Models**
- **Custom lighting & materials**

---

## 🎮 Features

- Cinematic intro animation
- Interactive 3D rings
- Click-to-focus product view
- Drag rotation for detailed inspection
- Dynamic specs panel
- Smooth transitions & animations
- Minimal luxury typography and layout
